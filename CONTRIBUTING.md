# Contributing

Open an issue for a reproducible bug or a focused proposal. Include the component, operating system, dependency versions, steps, expected behaviour and observed result. Use a minimal fictional example. Do not post credentials, learner profiles, participant responses, videos or real research exports.

For a code change, create a branch and a pull request. Explain the behavioural change, include a relevant regression test when needed, and update the guide that describes the behaviour. Keep algorithm changes distinct from claims about educational effectiveness. A changed metric needs a precise definition and evidence for any interpretation.

Run the checks described in the README and consult `VALIDATION.md` for release limitations. Documentation uses GitHub Flavored Markdown, relative links to source files, fenced runnable examples and explicit units. French guides accompany the English entry point. Prefer precise explanations over promotional claims or repeated keywords.

Contributions must be compatible with the MIT license and respect licenses of dependencies and materials. Follow `SECURITY.md` for security concerns.
